# Datheon Full Stack Web Development Internship

Welcome to my project repository for the **Datheon Full Stack Web Development Internship**.

This repository contains the web development projects I am building to improve my frontend and full-stack development skills.

## Projects

### Task 1: FocusFlow — Productivity App

**Status:** Completed

A productivity application built using HTML, CSS, and JavaScript.

**Features**
- Add, edit, and delete tasks
- Categorize tasks as Work, Personal, or Study
- Mark tasks as completed or undo completion
- Search and filter tasks
- Set due dates and identify overdue tasks
- Track task statistics and completion progress
- Save tasks in browser Local Storage
- Drag and drop to reorder tasks
- Responsive layout and animations

**Technologies:** HTML5, CSS3, JavaScript, Local Storage

### Task 2: Weather Dashboard

### Task 3: E-commerce Website

**Status:** Planned

Planned features include product listings, filtering, a shopping cart, quantity controls, price totals, and a checkout modal.

### Task 4: Medical Landing Page

**Status:** Planned

A modern, responsive medical landing page based on the assigned reference design.
